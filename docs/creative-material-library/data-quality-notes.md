# 创作素材库：使用与维护边界

本目录中的素材用于为 Bot 创作提供差异化参考。它不是事实知识库、Bot Prompt 模板库，也不是默认注入 Agent 上下文的内容。

## 使用原则

- 仅通过 `creative_material_search` 从已允许检索的素材表中取少量记录；
- 检索结果只作为启发，必须结合当前用户目标改写、组合、反转或具体化；
- 不照搬素材原文、不把素材当事实、不因检索到素材自动修改 Bot；
- 无论是随机取样还是组合筛选，都应返回少量短素材，避免整本设定集或大段原文进入上下文；
- 当前 Skill 判断是否需要检索、需要哪个内容维度；Tool 只负责按 Tag 取数。

## 允许进入检索表的内容

优先保留能够改变互动体验的、可再创作的内容，例如：

```text
角色驱动与关系结构
世界规则、资源、代价与信息边界
可进入的场景、持续冲突与叙事装置
用户行动、反馈、后果与互动机制
有具体互动作用的生活、感官或表达细节
```

## 不进入通用检索表的内容

```text
NSFW、未成年敏感、非自愿或违法导向内容
仅依赖特定作品/IP 的专属设定原文
正则脚本、变量表、状态栏、按钮、自动触发和其他旧平台运行时配置
空条目、分隔标题、禁用条目、纯目录、格式模板和无互动价值的词表
未经整理的超长原文或整本世界书
```

IP/同人来源只能被改写为无专属名词的抽象机制或结构；本目录不代表已解决来源授权或分发审核问题。

## 入表与长文本

- 素材表保存改写后的短素材单元，而不是原始世界书全文；
- 较长内容按语义职责提取，例如规则、关系、地点、冲突或互动入口；不要按固定字符数机械切块；
- 保留最小来源引用以便内部追溯，但不把来源原文作为常规 Agent 上下文；
- Tag 使用 `genres`（题材/体验）与 `material_types`（内容作用）两个维度。具体枚举、分布与回退策略由素材库整理结果维护。

## 维护检查

新增或更新素材前，确认：

1. 是否能说明它会怎样改变角色、关系、规则、场景或用户行动；
2. 是否已去除旧平台运行时语义、专属 IP 名词和不适合通用使用的内容；
3. 是否足够短且自包含，适合少量检索返回；
4. 是否能用 `genres` 与一个 `material_type` 清楚描述；
5. 是否仍符合当前安全与分发要求。
