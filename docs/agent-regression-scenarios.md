# Agent 回归场景

下列场景用于验证 Agent、Tool 与三栏工作区语义。

1. **自由探索**：用户说“想做一个房租模拟器”。Agent 可讨论、用 Choice 或创作素材参考；不自动创建 Bot 或 Artifact 页面。
2. **新建 Bot**：用户明确要求创建。Agent 准备内容和确认；创建后 Bot 是独立实体，过程对话不会自动变成 Bot 数据。
3. **已有 Bot 局部修改**：用户修改欢迎语。读取目标 `basic`，生成最小变更；不重写 `content`。
4. **浏览 Bot 三块内容**：用户打开基础/内容/高级设置。右侧创建/读取对应 `bot_basic`、`bot_content`、`bot_advanced` 页面；编辑页面不自动写 Bot。
5. **应用业务 Artifact**：用户将 `bot_content` 页面应用给 Bot。读取 Artifact 与目标 Bot，明确确认后由 `bot_workspace.update` 写入；Artifact 仍存在于当前对话浏览器。
6. **常规 Artifact**：图片、文本、代码或文件可在右侧以常规页展示，但不自动成为 Bot 内容。
7. **Artifact 上下文控制**：右侧有多个页面时，下一轮只带目录；用户明确打开/引用时才读取对应正文。
8. **查找另一个 Bot**：当前工作对象 A，用户查看 B。可读取 B，但不自动切换 A。
9. **Choice / Confirmation**：用户不操作控件、直接发新消息时，旧控件失效；不把它视为授权。
10. **图片链路**：确认图片方案后创建图片任务；结果在中间原位更新，前端处理轮询和选中；用户主动点“设为封面”才执行明确业务操作。
11. **归档/删除**：Bot 更新、归档、删除默认确认；明确针对本次操作的免确认授权可例外，删除前仍说明影响。
12. **长任务**：Activity 展示事实阶段；Todo 默认留在对话过程，需要右侧可操作页时才创建 Artifact。
13. **外部素材**：创作 Skill 只在泛化/缺失/同质化风险时调用素材检索；结果不自动写入 Bot 或创建右侧页面。
