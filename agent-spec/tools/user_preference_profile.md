# `user_preference_profile`

按需读取用户有权限访问的历史创作会话，返回与当前任务相关的偏好参考。结果不能覆盖最新用户请求、当前工作对象或已读取的 Bot 内容。

## 何时调用

仅当用户明确要求参考、延续或比较过去作品，或要求总结自己历史创作偏好、按之前风格继续创作时调用。不要因“可能有帮助”自动调用。

## 语义

- 只查询与当前任务有关的最小历史范围；
- 输出区分用户明确偏好、重复趋势、约束和不确定推断，并保留来源；
- 结果是参考，不是当前 Bot 事实，不自动写入 Session、Artifact 或 Bot；
- 若采纳历史偏好会实质改变当前方案，使用全局 Choice 或 Confirmation 让用户决定；
- 当前用户请求、已确认 Artifact 或已读取 Bot 内容与历史偏好冲突时，以当前事实为准。
